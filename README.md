# seeton

競技プログラミングとゲーム制作を軸に、Web 上で動く遊びや実験的なプロトタイプを作っています。  
アルゴリズムの楽しさと、触ってわかる体験づくりの両方が好きです。

## 興味のあること

- 競技プログラミング
- ゲーム制作
- ブラウザで動くインタラクティブな体験づくり
- AI / 暗号まわりの実験的なプロトタイプ
